# Eazara website

A cinematic React + TypeScript + Vite + Tailwind website built around the supplied cyber-lion hero video.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints in the terminal.

## Hero video

The supplied video is stored at:

`public/videos/eazara-lion.mp4`

## Easy edits

- Main page content: `src/App.tsx`
- Styling: `src/index.css`
- Replace the contact email in `src/App.tsx` if needed.
- Replace the founder card with a real founder image later if desired.
